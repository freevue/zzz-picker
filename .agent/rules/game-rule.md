# 경기 규칙 (Game Rule)

`zzz-picker`는 젠레스 존 제로(Zenless Zone Zero)의 고난도 콘텐츠인 **강습전**을 기반으로 진행되는 경기 운영 시스템입니다.
2명의 선수(A선수, B선수)가 각각의 파티를 구성하여 강습전을 진행하며, 최종 계산식에 의해 더 높은 총점을 획득한 선수가 승리합니다.

---

## 1. 강습전 기본 규칙

- **보스 구성**: 시즌마다 3종류의 보스(시유 방어전/강습전 라인업)가 상대 대상으로 제공됩니다.
- **제한 시간**: 라운드당 **3분 (180초)**입니다.
- **파티 구성**:
  - 하나의 보스를 상대할 때 **3명의 캐릭터(에이전트)**와 선택적으로 무기(W-엔진)를 사용합니다.
  - 1라운드에서 사용한 캐릭터/엔진은 2라운드에서 중복 사용할 수 없습니다. (2개 독립 파티 구성)

---

## 2. 경기 모드 (Match Types)

경기는 단판으로 진행되며, 총 2개 라운드(1Round, 2Round)로 구성됩니다.

| 경기 모드 | 모드 키 (`MatchType`) | 보스 선택 방식 | 코스트 제한 |
| :--- | :--- | :--- | :--- |
| **정식 로프꾼** | `original` | 1R: 각 선수 희망 보스 선택<br>2R: B선수가 선택한 공용 보스 공통 대결 | **24 Cost 제한**<br>(잔여 보너스 및 초과 감점 적용) |
| **레전드 로프꾼** | `legend` | 1R: 각 선수 희망 보스 선택<br>2R: B선수가 선택한 공용 보스 공통 대결 | **Cost 무제한** |
| **공허사냥꾼** | `unlimited` | 1R/2R: 각 선수마다 임의의 보스 자유 선택<br>(보스 선택 및 밴 페이즈 생략) | **Cost 무제한** |

---

## 3. 점수 계산식 (Score Calculation)

각 라운드 종료 후 입력된 **기본 점수**와 **소요 시간**, 그리고 사용한 **총 코스트**를 결합하여 최종 총점을 산출합니다.

### 1) 시간 보너스 (`calcTimeScore`)
- 180초(3분) 이내 클리어 시, 남은 시간(초)에 비례하여 보너스 점수가 지급됩니다.
$$\text{시간 보너스} = \max(180 - \text{소요 시간(초)}, 0) \times 333\text{점}$$

### 2) 코스트 보너스 및 페널티 (`calcCostBonuse`) - 정식 로프꾼 한정
기준 코스트는 **24 Cost**입니다.

- **코스트 절약 시 (Cost $\le$ 24)**:
  - 잔여 Cost 1당 라운드 점수의 **+5% (0.05)** 보너스 배율을 지급합니다.
  $$\text{코스트 배율} = (24 - \text{사용한 Cost}) \times 0.05$$
- **코스트 초과 시 (Cost $>$ 24)**:
  - 초과 Cost 1당 라운드 점수의 **-2% (0.02, `SETTING.MINUS_RATE`)** 페널티 감점이 적용됩니다.
  $$\text{코스트 배율} = (24 - \text{사용한 Cost}) \times 0.02 \quad (\text{음수 값})$$

### 3) 최종 점수 공식

$$\text{최종 총점} = \Big[(\text{1R 점수} + \text{2R 점수}) \times (1 + \text{코스트 배율})\Big] + (\text{1R 시간 보너스} + \text{2R 시간 보너스})$$

> `레전드 로프꾼` 및 `공허사냥꾼` 모드는 코스트 배율이 0으로 처리됩니다.
