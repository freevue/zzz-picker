zzz-picker는 젠레스 존 제로의 콘텐츠인 강습전과 관련된 서비스입니다.
2명의 선수가 각각의 파티를 구성하여 강습전 진행하며, 높은 점수를 가진 사람이 이기는 경기입니다.

## 강습전

- 강습전은 특정의 보스를 상대로 시간안에 최대한의 점수를 뽑아내는 콘텐츠입니다.
- 시즌마다 3종류의 보스를 상대해야 합니다.
- 시간은 3분이며, 최대 점수는 65,000점입니다.
- 각 보스마다 약점과 강점이 존재합니다.

## 강습전 파티 구성

- 하나의 보스를 상대할때 3종류의 캐릭터를 사용합니다.
- 하나의 보스를 상대했으면, 해당 파티의 구성원은 다른 보스를 상대할 수 없습니다.

## 사전 설정

- **선수 구성**: 선수는 A선수, B선수로 총 2명으로 구성됩니다.
- **경기 구성**: 경기는 `정식 로프꾼`, `레전드 로프꾼`, `공허사냥꾼`으로 구성됩니다.
  - 경기는 단판으로 진행되며, 경기는 총 2개 라운드로 구성됩니다.
  - 각 라운드마다 점수가 있으며, 점수는 최종 계산식에 사용됩니다.
- **Cost**: 각 경기마다 Cost라는 제한을 둡니다. Cost를 넘어가는 파티를 구성할 수 없습니다.
- **BanPick**: 참가자들은 규칙에 맞추어 밴픽을 진행합니다.
- **보호캐릭터**: 어떠한 이유로 보호된 캐릭터의 경우 밴을 할 수 없습니다.

## 라운드

### 정식 로프꾼

- 1라운드의 경우 각 선수마다 희망하는 보스를 선택할 수 있습니다.
- 2라운드의 경우 B선수가 선택한 보스를 공통으로 상대합니다.
- 각 선수는 총 24 Cost를 가지고 2개의 라운드를 진행할 2개의 파티를 구성해야합니다.

### 레전드 로프꾼

- 1라운드의 경우 각 선수마다 희망하는 보스를 선택할 수 있습니다.
- 2라운드의 경우 B선수가 선택한 보스를 공통으로 상대합니다.
- 각 선수는 Cost 제한 없이 2개의 라운드를 진행할 2개의 파티를 구성해야합니다.

### 공허사냥꾼

- 1라운드의 경우 각 선수마다 임의의 보스를 선택할 수 있습니다.
- 2라운드의 경우 각 선수마다 임의의 보스를 선택할 수 있습니다.
- 각 선수는 Cost 제한 없이 2개의 라운드를 진행할 2개의 파티를 구성해야합니다.

## Cost 구성

### 캐릭터 Cost 구성

| 구분     | 선택 | 돌파당 |
| -------- | ---- | ------ |
| S급 픽업 | 1    | 1      |
| S급 상시 | 0    | 0      |
| A급 상시 | 0    | 0      |

#### 예시

- S급 픽업 캐릭터 3돌파 선택: (3 \* 1) + 1 = 4
- S급 상시 캐릭터 2돌파 선택: (2 \* 0) + 0 = 0
- A급 상시 캐릭터 6돌파 선택: (6 \* 0) + 0 = 0

### 무기 Cost 구성

| 구분      | 선택 | 돌파당                               |
| --------- | ---- | ------------------------------------ |
| S급 픽업  | 1    | 0.5                                  |
| S급 상시  | 0    | 1 (`돌파 등급이 4, 5인 경우 +1한다.` |
| A급 / B급 | 0    | 0                                    |

#### 예시

- S급 픽업 무기 1돌파 선택: (0.5 \* (1 - 1)) + 1 = 1
- S급 픽업 무기 3돌파 선택: (0.5 \* (3 - 1)) + 1 = 2
- S급 상시 무기 2돌파 선택: 0 + 0 = 0
- S급 상시 무기 5돌파 선택: 1 + 0 = 1
- A급 / B급 상시 무기 5돌파 선택: (5 \* 0) + 0 = 0

### 촤종 예시

- S급 픽업 캐릭터 3돌파 선택 / S급 픽업 무기 1돌파 선택:
  - 캐릭터: (3 \* 1) + 1 = 4
  - 무기: (0.5 \* (1 - 1)) + 1 = 1
  - 최종: 4 + 1 = 5

## 점수 계산식

각 라운드의 결과에 따라 아래의 정보를 추가되어 최종 총점을 구합니다.

- 라운드가 종료되면 점수와 남은 시간을 입력합니다.
  - 각 라운드를 3분 이내 종료시 1초당 333점을 지급합니다.
- `정식 로프꾼`경기의 경우 사용한 Cost를 제외한 남은 Cost에 따른 보너스가 지급됩니다.
  - 잔여 Cost 1당 5%의 라운드 총점에 5% 보너스를 지급합니다.

### 최종 계산식

(1라운드 점수 + 2라운드 점수) \* Cost 보너스 배율 + 시간 보너스 = **총점**
