# Renew Components Guide

`apps/renew/app/components/` 디렉토리에 위치한 도메인 컴포넌트 인벤토리입니다.

## 컴포넌트 목록

| 컴포넌트 | 경로 | 역할 및 상세 설명 |
| :--- | :--- | :--- |
| **PlayGround** | `components/PlayGround/` | 참가자(A/B) 전용 밴픽/파티 구성 인터페이스 (모바일 우선, `max-w-lg`) |
| **HostDashboard** | `components/HostDashboard/` | 관리자(H) 전용 실시간 관전 및 경기 진행 3단 레이아웃 대시보드 |
| **CreateRoom** | `components/CreateRoom/` | 경기 모드 선택 및 선수 닉네임 입력 기반 방 생성 모달 |
| **CostDashboard** | `components/CostDashboard/` | 캐릭터 및 무기 코스트 실시간 표시 및 상세 내역 대시보드 |
| **Calc** | `components/Calc/` | 경기 종료 후 라운드 점수, 시간, 코스트 보너스/페널티 합산 계산기 |
| **Background** | `components/Background.tsx` | -40도 각도로 역방향 교차 회전하는 키네틱 사선 롤링 텍스트 배경 |
| **Chip** | `components/Chip/` | 실시간 연결 상태(`isConnected`), 역할, 라운드 정보 칩 |
| **AgentButton / EngineButton** | `components/*.tsx` | 캐릭터/엔진 선택 및 돌파 수치 조절 모달 트리거 버튼 |

## 핵심 컴포넌트 상세 명세

### 1. PlayGround (선수 밴픽 화면)
선수가 직접 보스를 선택하고, 밴 캐릭터를 제시/확정하며, 1R/2R 파티를 구성하는 핵심 컴포넌트입니다.

- **모바일 우선 설계 (`max-w-lg mx-auto`)**: 작은 화면에서도 조작이 용이하도록 최적화.
- **페이즈별 단계적 렌더링**:
  1. `Phase.COMMON_BOSS_SELECT`: B선수에게 공용 무대 보스 카드 그리드 및 선택 버튼 활성화 (original, legend 모드).
  2. `Phase.BAN`: A선수가 픽업 S 캐릭터 2명 제안(`proposeBan`) ➡️ B선수가 그중 1명 확정 밴(`selectBan`).
  3. `Phase.BAN_FIX`: B선수가 이전 밴과 다른 포지션(딜러 ↔ 서포터)의 픽업 S 2명 제안 ➡️ A선수가 1명 확정 밴.
  4. `Phase.PICK`: 1R/2R 탭 전환, 3인 에이전트 슬롯 + 엔진 슬롯 선택, 하단 플로팅 실시간 코스트 바 연동.

### 2. HostDashboard (호스트 대시보드)
3단 분할 레이아웃으로 설계되어 경기 전체를 한눈에 모니터링하고 방송 화면으로 송출할 수 있습니다.

```text
┌─────────────────┬─────────────────┬─────────────────────────────────────┐
│ [좌측: 규칙/제어] │ [중앙: 밴/보스]  │ [우측: 메인 경기판 & 결산]          │
│                 │                 │                                     │
│  ← 홈 이동      │  경기 타입 배지  │  선수 닉네임 (A vs B) & 접속 칩    │
│  특수 룰 텍스트  │  공용 보스 슬롯  │  ─────────────────────────────────  │
│                 │  허용 캐릭터     │  1 Round: A파티 ── VS ── B파티     │
│                 │  밴 결과 현황    │  2 Round: A파티 ── VS ── B파티     │
│                 │  (A 밴 → B 밴)  │  (타이머, 점수, 에이전트/엔진 슬롯) │
│                 │  캐릭터 일러스트 │  ─────────────────────────────────  │
│                 │                 │  [파티보기 ↔ 결산하기 슬라이딩 토글] │
│                 │                 │  결산 시: 시간 점수, 코스트 계산 합산│
└─────────────────┴─────────────────┴─────────────────────────────────────┘
```

- **실시간 반응형 동기화**: `useMatch()` 컨텍스트를 구독하여 A/B 선수의 클릭 이벤트가 즉시 브로드캐스트되어 반영됩니다.
- **좌우 대칭 구조**: A선수는 좌측 정렬, B선수는 `flex-row-reverse` 우측 대칭 정렬로 가독성을 극대화합니다.
- **원클릭 결과 결산 (`Calc`)**: 경기 종료 시 라운드 점수와 남은 시간, 코스트 보너스/페널티를 자동 계산하여 최종 우승자를 판별합니다.
