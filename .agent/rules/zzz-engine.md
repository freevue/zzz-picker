# 엔진(무기) 정의 (Engine Definition)

`zzz-picker`에서 사용되는 무기인 **W-엔진(Engine)**에 대한 도메인 규칙입니다.

---

## 1. W-엔진 등급 (Rarity)

| 구분 | 설명 | 코스트 기본값 (1돌) |
| :--- | :--- | :---: |
| **S급 픽업 (전용)** | 특정 캐릭터 전용 옵션을 지닌 한정 픽업 S급 W-엔진 | 1 Cost |
| **S급 상시** | 상시 채널에서 획득 가능한 일반 S급 W-엔진 | 0 Cost |
| **A급** | 상시 및 제작으로 획득 가능한 범용 A급 W-엔진 | 0 Cost |
| **B급** | 게임 초반 기본 제공 B급 W-엔진 | 0 Cost |

---

## 2. 돌파 (Rate)

- 모든 W-엔진은 **1돌파 ~ 5돌파**까지의 재련 단계를 가집니다.
- 기본값은 **1돌파**입니다.
- **S급 픽업 엔진**: 1돌파 상승마다 +0.5 Cost가 추가됩니다 (최대 5돌 3 Cost).
- **S급 상시 엔진**: 1~3돌파는 0 Cost이나, 4돌 또는 5돌 장착 시 +1 Cost가 가산됩니다.
- **A급 / B급 엔진**: 돌파 수치와 상관없이 항상 0 Cost입니다.

---

## 3. 전용 무기 (Exclusive Engine)

- 특정 캐릭터의 성능을 극대화하기 위해 매칭된 고유 무기를 의미합니다.
- DB 테이블 `engine`의 `exclusive_agent_id` 컬럼으로 대상 캐릭터와 연결되어 있습니다.
