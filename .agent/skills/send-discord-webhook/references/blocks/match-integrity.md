# 블록 규격: `match-integrity` (경기 기록 자동 점검 및 정리 브리핑)

정기 무결성 검사(`sync-match-integrity`)가 끝난 후, 디스코드 채널에 **일반 사용자 및 운영진 누구나 직관적으로 이해할 수 있는 친숙한 표현**과 **가장 깔끔한 인라인 하이라이트 서식**으로 점검 결과를 보고하는 전용 블록입니다.

---

## 1. 블록 메타데이터

- **블록 타입 식별자**: `match-integrity`
- **임베드 색상**: `3066993` (에메랄드 그린, `#2ECC71`)
- **기본 제목**: `🛡️ 경기 기록 자동 점검 및 정리 완료`
- **프로필**: 디스코드 채널 웹훅 설정에 등록된 페어리 아바타 및 이름을 우선 사용

---

## 2. 입력 데이터 스키마 (TypeScript)

```typescript
export interface MatchIntegrityBlockData {
  /** 정상 종료가 확인되어 공식 완료로 확정된 경기 수 */
  promotedCount: number;

  /** 24시간 동안 미완료 상태로 방치되어 깔끔하게 숨김 처리된 방 수 */
  hiddenCount: number;

  /** 현재 서비스에 정상적으로 등록되어 있는 총 공식 경기 수 */
  officialCount: number;

  /** 현재 경기 중인 방 수 (생성 후 24시간 이내로 안전하게 보호 중인 방) */
  activeCount: number;

  /** 전체 누적 매치 수 */
  totalCount: number;

  /** 실행 모드 ('manual': 수동 점검, 'auto': 정기 자동 점검, 기본값: 'manual') */
  executionMode?: 'manual' | 'auto';
}
```

---

## 3. 레이아웃 설계 지침

1. **깨지는 헤더 서식 배제**:
   - 디스코드 임베드 `fields` 내부에서는 `#`, `##` 헤딩 문법이 지원되지 않으므로, 대신 볼드와 인라인 코드(`**\`69개\`**`)를 조합하여 선명하고 굵은 가독성을 확보합니다.
2. **변동 수치 직관적 하이라이트**:
   - 변동 없을 때: `0건 (변동 없음)`
   - 변동 있을 때: `**+3건** (공식 확정)` / `**+12건** (목록 숨김)`
3. **점검 결과 요약의 최하단 배치**:
   - 상단에서 전체 수치를 먼저 파악한 후, 맨 마지막 단독 필드(`inline: false`)로 **`📋 점검 결과 요약`** 인용 박스(`> `)를 배치하여 깔끔한 결론을 제공합니다.
