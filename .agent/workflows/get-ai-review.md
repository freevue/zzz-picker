## PR AI 리뷰 분석 및 자동 반영 프롬프트

**[목표]**

특정 PR에 등록된 AI 코드 리뷰를 gh (GitHub CLI)로 읽어와 분석하고, 타당한 경우 현재 프로젝트 코드에 즉시 반영한 뒤 결과를 요약 보고한다.

**[실행 단계]**

1. 리뷰 데이터 수집

- `gh pr view <PR_NUMBER> --comments`를 실행하여 PR의 전체 맥락과 코멘트를 가져온다.
- 특히 코드 라인별로 달린 상세 리뷰가 필요한 경우 `gh api repos/:owner/:repo/pulls/<PR_NUMBER>/comments`를 사용하여 정확한 수정 위치를 파악한다.

2. 현재 프로젝트 분석

- 리뷰에서 지적된 파일들의 현재 코드를 읽어온다.
- AI 리뷰의 제안 사항이 현재 코드 구조와 충돌하지 않는지, 그리고 프로젝트의 코딩 규칙(TypeScript, 함수형 프로그래밍 등)에 부합하는지 분석한다.

3. 코드 반영 및 실행

- 반영이 가능하다고 판단된 항목들에 대해 실제 코드 수정을 진행한다.
- 수정 시 단일 목적 함수 원칙과 불변성을 유지하며 구현한다.

4. 최종 결과 보고 (주요 쟁점 리스트)

- 작업이 완료되면 아래의 Markdown 형식을 사용하여 주요 쟁점 위주로 요약 출력한다.

**[실행시 주의 사항]**

- 만약 인증이 되지 않은 사용자일 경우 작업을 중단하고 추가 인증을 요청할 것.
- 현재 인등된 계정이 현재 `origin repo`에 접근 권한이 없다면 작업을 중단하고, 인증 정보 수정을 요청할 것.
